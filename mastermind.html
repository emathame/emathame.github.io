The Mathematics Behind Mastermind

Mastermind is a deductive reasoning game. Each guess gives information that rules out some possible secret codes. A systematic player compares the feedback from several guesses to narrow the possibilities.

How is feedback calculated?

First count the digits that match in both value and position. Then compare the remaining unmatched digits, counting each occurrence at most once. For example, if the code is 1 2 3 4 and the guess is 1 3 4 5, the feedback is 1 correct position and 2 correct but in the wrong position.
