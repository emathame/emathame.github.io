The Mathematics Behind Four Fours

This puzzle explores order of operations, equivalent expressions, inverse operations and mathematical creativity. Brackets can change the result dramatically. For example, (4 + 4) ÷ 4 + 4 = 6, whereas 4 + 4 ÷ 4 + 4 = 9.

Each expression must use four separate occurrences of the digit 4. We use only addition, subtraction, multiplication, division and brackets—no concatenation, factorials, roots or decimal points.

How does the computer check an answer?

The game evaluates the entered expression using the usual arithmetic rules, including brackets and multiplication before addition. It also checks that exactly four 4s appear and that no other numbers or symbols are used. Arithmetic is evaluated as exact fractions, so rounding errors cannot turn an incorrect answer into a correct one.
