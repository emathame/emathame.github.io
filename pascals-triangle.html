The fractal connection

Colour each odd entry and leave each even entry pale. As the number of rows grows, a Sierpiński triangle emerges—the same fractal you explored in the Chaos Game.

The fractal view uses parity only (odd or even), so very large binomial coefficients need not be calculated.

Try these investigations

1. Why do the rows add to powers of 2?

The sum of row n, counting the top as row 0, is 2n. This follows from the binomial theorem: (1 + 1)n = 2n.

2. Where are the triangular numbers?

The third diagonal (counting the outside diagonal as the first) contains 1, 3, 6, 10, 15, … . These are the triangular numbers, given by n(n + 1)/2 for n = 1, 2, 3, … .

3. How do Fibonacci numbers appear?

Add entries along the shallow diagonals running upwards to the right. Their sums are 1, 1, 2, 3, 5, 8, 13, … . Select “Fibonacci diagonals” to see the first few highlighted groups.

4. What are binomial coefficients?

The entry in row n and position k (counting from 0) is written C(n,k) or “n choose k”. It counts the ways to choose k objects from n objects without regard to order. For example, C(5,2) = 10.

5. Why does a Sierpiński triangle appear?

Pascal's triangle follows the rule that each entry is the sum of its two parents. Considering entries modulo 2, an entry is odd precisely when its parents have different parity. This repeated parity pattern creates self-similar triangular gaps. It is a different construction of the same Sierpiński fractal formed by the Chaos Game.
