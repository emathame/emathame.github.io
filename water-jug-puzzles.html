The Mathematics Behind This Puzzle

Water jug puzzles are examples of state-space problems. A state is an ordered pair (a, b), where a and b are the amounts of water currently in the two jugs. Each permitted operation changes one state into another.

Why does the greatest common divisor matter?

Suppose the jug capacities are A and B litres. Using filling, emptying and pouring operations, a positive target amount T (not exceeding the larger capacity) is measurable precisely when gcd(A, B) divides T.

For example, with 3-litre and 5-litre jugs, gcd(3, 5) = 1, so every whole-number target from 1 to 5 litres is measurable. But with 6-litre and 10-litre jugs, gcd(6, 10) = 2, so exactly 5 litres cannot be measured.

How does the computer find the fewest moves?

The game uses breadth-first search to examine reachable states in increasing order of the number of operations. The first state containing the target therefore gives a solution using the fewest moves.

A mathematical challenge

Using a 6-litre jug and a 10-litre jug, explain why measuring exactly 5 litres is impossible, no matter how many legal moves you make.

Show Explanation

Both capacities are multiples of 2, so their greatest common divisor is 2. Initially both jugs contain 0 litres, an even quantity. Filling, emptying or pouring between the jugs preserves the property that each jug contains an even whole number of litres. Consequently, neither jug can ever contain exactly 5 litres.
